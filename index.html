RayCrafter evaluation

Optiland and RayCrafter against Zemax

For each optical design, how closely does the open-source ray tracer Optiland, and the lens-level design tool RayCrafter built on it, reproduce what Zemax OpticStudio gives?

What this is

Each design starts as a Zemax file exported from OpticStudio, together with the plots and numbers Zemax produces for it (the reference). We load the same file into Optiland, run the same analyses, and compare. Every page puts the verdict first (match, partial or fail, computed from stated tolerances), then the evidence: the Zemax output next to ours, then the full Optiland analysis. Problems we find in Optiland are written up in optiland_issues_found.md, and each one lists where it stands upstream in optiland/optiland (so far #1210, #1247, #1248 and a comment on #865).

The repository is also where RayCrafter is pointed at designs that largely work in Optiland, with the goal that they work in RayCrafter too.

Each design folder holds the Zemax export, a Zemax_reference_output/ folder (what we must match), an optiland_analysis/ folder (our best attempt, with a README listing every file) and the generated page in HTML_summary/.
